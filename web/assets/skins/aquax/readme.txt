Aqua X Winamp Skin
by Freddy Leitner (dreamer@dreamer.net)

Why another Aqua skin? Well, this one has been created from
scratch, taking the official Aqua screenshots as working base.
Simply because I didn't like the other Aqua skins out there -
most of them are crappy work, and the ones that are clean and
well done aren't very true to the original MacOS X Aqua style.
